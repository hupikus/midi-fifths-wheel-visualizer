This project was made because most other solutions are either vibecoded, bloated, or did not match the criterias by other reasons. 

![screenshot](screenshot.png)

This is a free and open-source atomic tool. If you need an advanced solution with more additional features, consider supporting [chordviz](https://www.chordviz.ca/) by Charles-Antoine Pouliot.  

This application brings realtime midi visualization with raylib C on native linux.

# Dependencies

Raylib and rtmidi.

# Compilation

```sh
make
```
